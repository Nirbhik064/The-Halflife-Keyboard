# The-Halflife-Keyboard.

Hey, so this is a custom mechanical keyboard designed by me with the help of a few guides over there on youtube.
I have fully designed the schematics by myself and also, have made the pcb for it.
I have tried to make it as a 65% keyboard with 68 keys and with leds under every key.
